It writes sessions.json, the file Upcoming Sessions reads, for you to paste into GitHub. Sign-ups for these sessions arrive by email.

      How to Publish It

      1. Fill in the new session and check the preview. To take sessions off instead, untick them under Already in sessions.json (you can leave the form empty).
      2. Check that Already in sessions.json lists every session you expect. If you published a change in the last few minutes and it isn't there yet, wait and reload this page, or that change would be lost.
      3. Click Copy.
      4. Click Open sessions.json on GitHub and sign in with an account that can edit the site. If the file opens for reading, click the pencil icon (Edit this file).
      5. Select everything in the file (Ctrl+A, or Cmd+A on a Mac) and paste, so the copied text replaces it all.
      6. Click Commit changes…, write a short message such as "Add session: Build a Working Stethoscope", and commit.
      7. Once the site is published, the session shows on Upcoming Sessions with its own sign-up page, and hides itself the day after it happens. Sign-ups for it arrive in the YME inbox.
