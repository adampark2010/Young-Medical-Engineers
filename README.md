# Young Medical Engineers

Static site for [www.medengineers.org](https://www.medengineers.org), built with
[Astro](https://astro.build). No client-side framework, no UI library.

## Commands

```bash
npm install        # once
npm run dev        # local server at http://localhost:4321
npm run build      # static output in dist/
npm run preview    # serve dist/ locally
npm run brand      # regenerate favicons and the OG image from the originals
npm run audit      # hard-rule checks against dist/ (run after build)
```

## Where things are

| Path | What |
|---|---|
| `src/content/copy.ts` | Every string of approved copy, word for word from the website update instructions. Edit copy here and nowhere else. |
| `src/content/board.ts` | Board roster. Set `bio` on a member to replace "Bio coming soon." |
| `src/content/nav.ts` | Route set and order. |
| `src/content/provisional-demonstrations.ts` | The Hands-on demonstrations program. Provisional, see below. |
| `src/config.ts` | Site constants, contact channels, the form endpoint, and the demonstrations switch. |
| `src/styles/tokens.css` | Colour, type and grid tokens. Every colour traces to a sampled logo value. |
| `src/styles/global.css` | Base styles, grid, forms, buttons. |
| `src/layouts/Base.astro` | Document head, fonts, skip link. |
| `src/layouts/Page.astro` | Inner page shell: masthead, page head, footer. |
| `src/pages/*.astro` | One file per route. |
| `src/brand/originals/` | The four logo PNGs, untouched. Imported by Astro's image pipeline for the masthead, footer and splash. |
| `public/brand/` | Derived assets (favicons, app icons, OG image). Generated by `scripts/derive-brand.mjs`; do not hand-edit. |
| `public/CNAME` | Custom domain for GitHub Pages. Must stay. |
| `scripts/approved-copy.json` | The 35 approved copy blocks, extracted from the instructions document, used by the audit. |
| `_old_site/` | The previous static site, kept for reference only. Safe to delete once the rebuild is live. |

## Deploying

The site deploys to GitHub Pages from `.github/workflows/deploy.yml` on every
push to `main`. One-time setup in the repository: **Settings > Pages > Build and
deployment > Source** must be set to **GitHub Actions** (not "Deploy from a
branch"). Clean URLs use a trailing slash (`/about/`), which GitHub Pages serves
directly.

## Provisional: Hands-on demonstrations

The team has not decided whether demonstrations run. Everything that exists
only because of them is gated on `SHOW_DEMONSTRATIONS` in `src/config.ts`:

- the Hands-on demonstrations item under Programs > Building interest
- "or demo" in the Contact topic "Request a talk or demo"
- "Help with demonstrations" on the Volunteer form

To drop demonstrations in one commit: set the flag to `false` and delete
`src/content/provisional-demonstrations.ts`. Note that the approved About
intro and two Contact FAQ answers also mention demonstrations in passing; those
are approved sentences and would need new wording from the team.

## Forms

Tutoring, Volunteer and Contact forms are built to spec but have no submission
endpoint yet (`FORM_ENDPOINT` in `src/config.ts` is `null`). Until one is set,
submitting shows the approved error message, which directs people to email.
When an endpoint exists (Formspree, a Google Apps Script, a Worker), set the
URL there; the form posts `FormData` with a `form` field naming the form.
